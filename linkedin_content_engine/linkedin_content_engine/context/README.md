# Context

`about_me.md` in this folder is a living, structured summary of James's real
background — career history, education, skills, notable projects, achievements. It's
separate from `drafting_engine/persona.py` on purpose: `persona.py` is *voice* (how he
writes, tone, cadence), this is *biography* (what's actually true about him). Drafting
pulls from both.

**Not committed to git** (see the root `.gitignore` — only this README is tracked),
same reasoning as `documents/` at the repo root: even though some of this will already
be public on LinkedIn, it's personal enough that it shouldn't default to being in a
repo. It stays local to this machine.

**How it grows**: say "save this" (or similar) about anything you want remembered, or
point me at a file in `documents/`, and I'll update `about_me.md` directly — read it
back any time to see exactly what's in there and correct anything that's wrong or
outdated.
