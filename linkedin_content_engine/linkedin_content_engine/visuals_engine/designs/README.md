# Baroni post templates

52 LinkedIn post templates: 26 designs, each with a light and a dark (`_dark`) version.

## Start here
Open `index.html` in a browser. It links to every template.

## What's in each file
- Every slide is a `<div class="slide light">` or `<div class="slide dark">` at exact pixel size: 1080 × 1350, or 1080 × 1080 for the announcement post. All text is live.
- Text spots are marked `{{field_name}}`. Gold italic accents are marked `<em>{{headline_gold}}</em>`.
- Repeating items sit between `<!-- repeat: name -->` and `<!-- /repeat: name -->`. Copy the marked element once per item.
- Fields marked "auto" are worked out by your filler: item numbers (01, 02…), slide counters, `progress_pct` (0–100), and `item_highlight` ("yes" or blank).
- Each field's max word count is listed under the slides.
- The preview buttons switch between sample text at max items, sample text at min items, and bare field names.
- Add `?raw` to the URL to see the untouched template.
- Carousels keep all their slides together in one file.

## Keep together
The templates load images from `assets/`. Keep that folder next to the HTML files.
