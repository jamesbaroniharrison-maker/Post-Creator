## 1. Summary
Personal, semi-automated LinkedIn content engine for James / Baroni Applied Intelligence. A daily cron researches AI and market news into a Topic Bank. Posts are then drafted in James's voice: a stylometric voice profile plus a hand-authored persona, with CPIO/THBM rotation, a privacy scrub and audit gates. James reviews every draft (Accept / Redraft / Reject) in a Reflex dashboard, and branded post visuals are rendered from Claude Design HTML templates. Nothing publishes without a human click. It runs on localhost, with remote access over Tailscale and a login.

## 6. Reusable Processes & Workflows
1. **Grow the voice corpus:** dashboard Voice page (paste a post, Gemini Q&A, or a full labelled transcript -> `ingestion.add_sample` / `parse_labeled_conversation`) -> `voice_engine.run` rebuilds the profile and writes `context\voice_profile_report.md` -> Home page corpus-health card shows per-source counts.
2. **Draft -> score -> refine:** topic -> `research_topic` (Tavily, deny-list, credibility filter) -> `assign_rotation` -> CPIO plan + THBM prompt (`_SYSTEM_PROMPT_TEMPLATE` + persona + profile + embedding-picked few-shots) -> N drafts scored by register-aware Burrows' Delta -> best kept if under `DRAFT_QUALITY_FLOOR` (else re-roll up to 2 rounds) -> audit-gate call (1 retry) -> em-dash regex + money redaction -> `post.voice_delta` stored.
3. **Daily research cron:** `research_cron.run` (07:00 task) -> `queries.py` -> discover -> score (Gemini) -> dedup (30-day lookback) -> Topic Bank -> calendar matching.
4. **Weekly loop:** Settings weekly template -> "Prepare next week" auto-drafts -> Review -> accepted posts auto-scheduled by `scheduling.py` -> visuals rendered -> `exports.py` ready-to-post bundles -> Sunday digest email.
5. **Narrow-call reliability pattern:** if a small local model misses one rule in a busy prompt, split that rule into its own yes/no LLM call plus a deterministic regex. Used for the scrub verify, audit gates and source credibility.

## 10. Known Issues, Gotchas & Lessons Learned
- **Duplicate of global library:** `visuals_engine\designs\*.html` and `assets\logos\*` are byte-identical copies of `! Branding\posts\` and `! Branding\logos\`. They were copied deliberately so the engine is self-contained, but they will drift. Proposal: point `designs.DESIGNS_DIR` at `D:\Work\! Branding\posts` (or sync with a script) and keep the copy only for client handoffs.
- Shared venv history: `venv\` was created in the Ben Holmes project; wrappers point there. Always call `venv\Scripts\python.exe`.
- Ollama silently caps context at 2048 unless `num_ctx` is set. `llama3.2` echoes schema placeholders, so use `llama3`.
- Gemini `google_search` grounding needs billing; flash models hit 20 req/day free caps. Hence Tavily + `flash-lite`.
- Scheduled Task registration fails silently without elevation.
- Ghost listeners on 8000-8005 push the backend to 8006; a reboot clears them. The Ben Holmes app uses 3001/8200.
- Small models miss rules bundled in busy prompts, so split each rule into its own narrow call (see Section 6.5).
- Corpus is thin on real posts (3 `linkedin_post`), so Delta on the `linkedin_post` register is noisy.
